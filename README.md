# HTML and CSS Practice

A collection of HTML and CSS exercises completed while learning frontend web development.

This repository contains practical examples covering webpage structure, text formatting, forms, tables, media elements, page layouts and CSS styling.

## HTML Practice

| Topic | Practice files | Concepts |
|---|---|---|
| HTML Basics | `h&ptags.html`, `Paragraphs&Text-Formatting.html` | Headings, paragraphs and text formatting |
| Lists | `Lists.html` | Ordered and unordered lists |
| Forms | `FoodPass.html`, `loginpage.html`, `studentRegistration.html`, `MusicBandRegistration.html` | Input fields, labels, buttons and form elements |
| Tables | `BookInventoryApp.html`, `timetable.html`, `familyPhotos.html` | Tables and structured information |
| Media | `Media.html`, `MusicBandRegistration.html`, `familyPhotos.html` | Images, audio and video |
| Page Layouts | `Portfolio.html`, `ProductLandingPage.html`, `SchoolAdvertising.html`, `Student_Webpage.html` | Navigation, sections and webpage structure |
| Technical Documentation | `TechnicalDocumentationPage.html` | Navigation-based documentation layout |
| Other Elements | `PageOfPlayingCards.html` | HTML elements and page structure |

## CSS Practice

The CSS exercises cover:

- Text styling, fonts and colours
- Backgrounds, margins and spacing
- Flexbox layouts
- Fixed positioning
- Table styling
- Responsive layouts using media queries
- Styling forms and page components

## Technologies

- HTML5
- CSS3

## Running the Examples

1. Clone or download this repository.
2. Open the `HTML` folder.
3. Open any `.html` file in a web browser.
4. For editing, open the repository in Visual Studio Code.
